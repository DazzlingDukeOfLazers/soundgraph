# MIDI examples

Tunes for the piano roll's **File > Import MIDI**. Provenance, in the spirit of
docs/fm-import-sources.md: every file here must say where it came from and why it
may be here.

- `ode-to-joy.mid` — generated by `tools/make-demo-midi.mjs`. The melody is
  Beethoven's (1824, public domain everywhere); the encoding is this repository's
  own. Format 0, 96 ticks per quarter — the plainest SMF spelling, which is the
  point: it is what the importer is tested against.
- `bach-invention-08.mid` — J.S. Bach, Invention No. 8 in F major, BWV 779, from
  the Mutopia Project (mutopiaproject.org/ftp/BachJS/BWV779/bach-invention-08/),
  listed there as **Public Domain**. Format 1, three tracks, 384 ticks per
  quarter — the real-world case: multiple tracks merged on absolute ticks, a
  division the generator never uses, and more music than the roll's sixteen-bar
  cap holds (the importer says how much stayed behind).
