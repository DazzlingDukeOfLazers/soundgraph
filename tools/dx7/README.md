# DX7 banks

`banks/algorithm-demos.syx` is an **original bank generated by
`tools/dx7-make-demo-bank.mjs`** — 32 voices, one per algorithm, written to exercise
every topology through the import path. It is this repository's own work and is
dedicated to the public domain; regenerating it is deterministic.

No third-party bank is vendored, on purpose. The community DX7 patch pools are
tolerated rather than licensed, and the Yamaha factory ROM banks are not ours to
ship — `docs/fm-import-sources.md` has the survey. `tools/dx7-import.mjs` imports any
32-voice `.syx` dropped into `banks/`, so using your own collection is a copy and a
rerun; whether the *result* may be redistributed follows the bank's own licence, which
is between you and it.

The 32-algorithm routing table inside the importer is transcribed from Dexed's `msfa`
engine (`fm_core.cc`, Apache 2.0) and decoded by executing its bus machine rather than
by reading panel charts. Stage-1 fidelity — what is applied and what is pending — is
documented at the top of the importer and recorded per patch in the metadata. The
planned oracle is the msfa engine itself, in the same pattern as sfxr and Nuked-OPL3.
