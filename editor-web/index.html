    About SoundGraph

    SoundGraph is a visual synthesizer project for building, hearing, and learning signal flow. The central artifact is a portable patch file: the same graph runs in this browser, in the full editor, on the desktop, and on cheap embedded hardware.

    What runs where

      What this page stores

      In your browser, and nowhere else unless you ask: a random id so a repeated report updates in place rather than becoming two, how far the introduction got, the patch you last saved locally, and whether you answered the mailing-list invitation. Clearing site data clears all of it.

      If you join the mailing list, your address is sent to the Mutant Factory feedback service and read by a person. Nothing else leaves this page — not your patch, not your audio, not what you played.

      SoundGraph is a Mutant Factory project: new interfaces for things that already exist, with the machinery left open whenever possible.

      Help

      Playing

      • Press Start audio first — browsers will not make sound until you do.
      • The on-screen keys, your computer keyboard and any connected MIDI keyboard all play the patch.
      • z and x shift the keyboard an octave.

      Reading the graph

      • Signal runs left to right. Thick lines carry audio; thin ones carry control.
      • Selecting a node finds it in the patch source.
      • Moving a control lights the node it drives.

      What this page cannot do

      This page reads a graph. It does not let you add a node or drag a cable — that is the full editor's job, and keeping the two apart is why a patch means the same thing in both. See About for what runs where.

      No sound?

      • Check the system volume and which output device the browser is using.
      • The level meter beside Start audio moves when the patch is making signal, even if you cannot hear it.
      • A patch with errors does not play. The problems appear under the patch source.
